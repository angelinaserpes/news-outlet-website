# Veridian Digest — News Outlet Website 📰

A clean, editorial news website covering breaking news, sports, culture, and business. Built as a front-end design exercise focused on information hierarchy and news layout patterns.

## Stack

| | |
|---|---|
| Framework | React + TypeScript |
| Styling | Tailwind CSS + shadcn/ui |
| Build | Vite |

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
